# SecKit

## Приложение для генерации и проверки на стойкость паролей

- Отличие этого приложения от сотни таких же - БЕЗОПАСНОСТЬ.
- Пароль генерируется прямо в браузере и никуда не отправляется.

## Возможности

- генерация паролей(с выбором символов).
- проверка стойкости паролей(по заданным параметрам).
