# seckit-learn-frontend

Приложение для генерации и проверки на стойкость паролей. Подойдет для любого пользователя, которому нужны эти функции.

Возможности:
    - генерация паролей(с выбором символов).
    - проверка стойкости паролей(по заданным параметрам).

План версий:
текущая -> v0.01 (подготовка к разработке, создание скелета проекта).
        - v0.1 (этап 1, генератор паролей + анализ стойкости — чистый JS, DOM).
        - v0.2 (этап 2, проверка по базе утечек (Pwned Passwords API, k-anonymity, Web Crypto API) + поиск CVE через публичный API).
        - v1.0 (этап 3 React + TypeScript).
        - v1.1 (этап 4 тесты, CI, деплой).
        - v1.5 (этап 5 архитектура, мини-дизайн-система, производительность, a11y).
        - v2.0 (этап 6 ИИ-ассистент объясняет CVE простым языком (стриминг) + свой Node.js-бэкенд (ключи только на сервере)).
